原理（低速准静态近似）
q_urdf = sign * (encoder_ticks - calibrated_zero_ticks) * 2π/4096
motor_torque = calibrated_Nm_per_A * (signed_current_A - calibrated_bias_A)
external_torque_estimate = gravity(q) - motor_torque
M_virtual * target_acceleration + D * target_velocity = external_torque_estimate（带小死区）
积分得到位置目标，由舵机模式0跟踪。直接电流反馈仍包含摩擦、惯性、齿轮效率和回驱效应；不是力传感器。
没有增加刚性回零弹簧，没有自动回零，没有静止超时退出。
导纳速度/加速度/目标偏移限幅是外环稳定性约束；不是旧版跟随误差停止。
连续保持/导纳无固定时长。2A为每轴停止阈值，1.8A输出指令实测可被瞬态反馈电流超过。
电源总电流和舵机电流反馈不是同一测量。

源码参数：GELLO导纳参数.py，所有入口无必需命令行参数。

简化的零位/方向记录（不要求手动精确转到10度）
先按图A摆放，运行 python GELLO记录URDF零位.py。
再按图B所示方向分别改变六轴，每轴4～30度即可，运行 python GELLO记录URDF方向.py。
图B用于确定各轴方向，不把手动转动幅度假定为精确10度。
底座-Z是否竖直向下仍须确认，在GELLO导纳参数.py设置GRAVITY_DIRECTION_CONFIRMED。
此简化方案依赖准确摆到URDF零姿态。若零姿态无法摆到，应采用下面的已知角度多姿态拟合方法。

已知角度多姿态拟合与后续辨识次序
1. 对照 evidence/gello-admittance/urdf-reference-poses.png 确认URDF零姿态和底座-Z重力方向。
   当前映射要求模式0全角度反馈。不能在模式4断电坐标上直接记录，再用于模式0控制。
2. 手动摆到一个已知URDF姿态，设置KNOWN_URDF_Q_DEG（默认图中Pose A全0），运行：
   python GELLO记录URDF姿态.py
   此脚本只读，不使能、不改硬件零位。记录到 logs/gello_urdf_pose_samples.jsonl。
3. 再摆一个已知姿态，例如图中Pose B=[10,-10,10,10,10,10]度，修改源码中的KNOWN_URDF_Q_DEG后再次记录。
   每轴至少8度有效变化，拟合残差不超过1.5度；可增加更多已知姿态。
   确认实际安装重力方向后设置GRAVITY_DIRECTION_CONFIRMED=True并重新记录。
   输出 gello-urdf-mapping.json；六轴都verified才用于实机控制。
   目测摆到10度不足以保证高精度，建议角度量具或准确机械基准；未知姿态不要假填角度。
4. python GELLO导纳只读检查.py
   显示实际URDF角度、电流、模型重力矩，不使能。首先验证方向/范围/重力矩变化。
5. 静态电流辨识：换至少10个不同、能自行保持且无外部托举力的姿态。
   确认无外力后在源码中设置STATIC_SAMPLE_NO_EXTERNAL_FORCE=True，每个姿态执行：
   python GELLO采集静态电流.py
   保持5秒，采最后2秒中位数，之后卸力；未稳定样本不写入辨识集。
   然后 python GELLO辨识电流力矩.py
   采用带偏置线性拟合，要求电流/重力矩有足够变化且R²和误差合格。
   这得到的是基于当前URDF的近似系数，需独立姿态实测验证，不能替代精确力矩传感器标定。
   重力变化不足的轴无法靠静态重力辨识（通常J1）；会标记inactive，仅位置保持。
   如需这些轴也参与导纳，必须另外用已知外加力矩标定；不猜测系数、不照搬其他轴。
6. 标定通过后 python GELLO导纳重力补偿.py
   六轴中辨识合格的轴运行导纳，未辨识轴与ID7保持当前位置，Ctrl+C卸力。
